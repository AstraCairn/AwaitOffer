# 使用说明

## 添加与导入

手动记录默认不依赖浏览器连接：填写公司、岗位和官网当前状态即可。已有进度不能直接清空；修正状态或选择标准阶段即可调整。

“导入书签”读取 Windows Edge 默认配置中的书签。先选择文件夹，再预览和勾选公司入口，包含子目录；同名文件夹通过完整路径区分。默认建议“秋招岗位”，没有这个名称也可以使用其他目录。每次最多导入 500 个入口，重复网址跳过。

导入只保存公司和官网入口，先作为手动记录；岗位显示“待确认岗位”，状态留空。敏感认证参数会被移除，个人中心导航路由会保留。书签导入不支持其他 Edge 配置或 HTML 文件，其他来源可以手动添加。

## 自动同步

先连接 Edge 扩展，再到“官网连接”管理公司。可以依次连接已有公司入口；在官网正常登录并进入投递记录页后，程序尝试读取岗位、批次、投递时间和状态。

同一官网连接可关联多个岗位，官网投递标识用于去重。尚未编辑的空白书签记录可原位转换为自动记录。已绑定的官网或模式不能直接替换，需要为新官网新增投递。

自动导入按设置中的毕业届别筛选，排除明确的实习、社招和其他届别；未注明届别的真实记录可以导入。存在多个匹配或字段不足时保留记录，不猜测投递身份。

本地服务、Edge 和扩展都在运行时才能定时同步。默认每天一次，可在设置中调整为 5–10080 分钟。电脑休眠后到期只补查一轮，不累计补查。手动同步不改变原定时节奏。

查询最多并发 3 个官网，同一连接共享查询；单站点失败不影响其他公司。自动查询使用独立窗口内最多 3 个复用标签页；主动打开的登录／验证页另外保留，不占用这三个标签页。

## 理解状态与提醒

- **招聘阶段**：简历筛选、笔试测评、面试中、待定／候补、已拿结果、已结束、待分类。筛选和测评没有固定先后顺序。
- **官网原文**：保留官网真实状态；同一标准阶段内文字变化也进入历史。
- **首次记录**：建立基线，不产生未读。首次记录前的状态开始时间未知，界面注明“自首次记录起”。
- **未读变化**：保留到主动标为已读，不会因再次同步而消失。标为已读不会删除历史。
- **本次变动**：最近一次自动查询任务发现的变化；手动编辑不改变该任务统计。
- **进行中**：筛选、测评、面试和明确待定状态之和，不包含未知状态。
- **已结束**：包括项目规则归为结束的“人才库”。明确结束的后续变化自动标为已读。

连接状态与招聘阶段分开显示。明确登录过期才提示去登录；验证码提示去验证；超时、字段无法解析和投递不匹配提示检查连接，同时保留最后成功读取的进度。

删除自动投递后会记录忽略项，避免下次同步重新出现。需要恢复时，在“官网连接”的忽略列表中选择“恢复导入”。

## 数据流

工作台通过本机 API 读写 SQLite，扩展将已解析的岗位和状态传给本机接入服务。网页登录信息留在浏览器中；扩展与服务配对使用单独令牌。

可选的“AI 辅助识别”需要 xAI 密钥。已知平台走常规适配器；部分未知自建站点可发送字段结构和经过处理的样例以识别字段。样例过滤敏感字段名，但可能保留岗位、状态、日期等短文本；不应把它理解成绝对匿名或完全离线。未配置时不会调用模型功能。清除本机密钥后，如果还配置了 `XAI_API_KEY` 环境变量，必须移除该变量并重启服务，才能停用后续调用。

诊断保存在本机 `data/diagnostics/`，可能含已解析的岗位、进度、请求路径以及字段结构，不含查询参数、完整响应和认证请求内容。即使经过处理，分享前也应自行检查。
