# 招聘站点适配

“实现解析”“曾验证成功”“在你当前账号可用”是不同状态。界面显示的成功读取情况仅代表本机连接；平台名称或权限清单不构成全站支持承诺。

| 平台         | 实现与限制                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------------ |
| 飞书招聘     | 从页面实际返回的投递、阶段数据及可见卡片读取，按官网 ID 关联。部分页面不公开完整阶段，使用实际显示的状态。   |
| Moka         | 解析投递记录；不同站点版本需单独核对。大疆的验证码查询页有单独的保留与暂停逻辑。                             |
| 北森         | 解析 ApplyId／Id、岗位名称和公开状态文字；品牌域名也可识别为北森。                                           |
| 部分自建官网 | 包含华为、阿里、快手、米哈游、荣耀、腾讯、联想、百度、京东、蚂蚁的字段解析或入口；不同站点的验证程度不一致。 |
| 其他官网     | 可保存手动入口，不保证自动读取。                                                                             |

部分飞书站点、大疆、卓驭和科大讯飞等曾有真实登录验证；这不代替当前页面与账号的验收。腾讯等仅有解析实现的站点不能据此宣称已验证可用。

京东仅在可唯一关联投递时自动绑定，多条记录且无法区分时提示人工处理。大疆已经打开的验证码结果页尽量保持原状；接口再次要求验证码时暂停对应查询，保留最后成功结果。保留页面不代表已经获得最新状态。

## 失败时的行为

网络超时、登录失效、验证码、字段缺失或岗位匹配冲突，都不会将原有进度覆盖为空值或猜测结果。无法识别的招聘阶段显示“待分类”，可手动指定分类。

## 新增适配器

提交可脱敏的结构和预期解析结果，添加单元测试，验证岗位、官网投递 ID、状态和投递时间。不要使用职位发布时间代替投递时间，不要根据数字状态码猜测未确认的官网文案。

单元测试验证字段解析，真实登录验证确认现场行为。未经真实验证的实现必须明确标注；诊断和测试 fixture 不得含 Token、Cookie、候选人资料或完整招聘响应。
