# 常见问题

## 启动失败或 Node 版本不符

运行 `node --version`，需要 24.15 及以上的 24.x。优先使用 `.node-version` 中的版本。在 PowerShell 中使用 `npm.cmd` 可避免脚本执行策略拦截。

依赖缺失时重新运行 `npm.cmd ci`，之后执行 `npm.cmd run build`。源码启动前需要构建；只下载 `extension/` 源码而未构建时，扩展脚本尚不存在。

## 端口被占用

面板默认使用 3180，浏览器接入服务固定使用 3182。先检查是否已有 AwaitOffer 实例运行；不要同时启动指向不同数据目录的浏览器接入服务。

可以设置 `PORT` 修改面板端口，但不能使用为接入服务保留的 3182。设置方法见[开发说明](development.md)。

## 工作台提示服务断开

确认服务窗口没有关闭。已有页面上的记录不会立刻消失，点击“重试连接”重新读取。关闭面板页面与停止本地服务是两件事；停止服务后定时同步也会停止。

## 没找到书签

当前只读取 Windows Edge 的 `Default` 配置。使用其他配置、Chrome 或其他浏览器时不会自动发现书签。文件夹名称无需固定，打开“导入书签”选择完整路径即可；没有可用书签时可手动添加投递。

文件夹在预览后被移动或删除时，请关闭并重新打开导入窗口，再选择文件夹。

## 同步按钮不可用

检查本地服务和 Edge 扩展是否已连接，以及是否存在自动投递。只使用手动记录时不需要同步；从公司操作菜单可以开启已适配官网的自动查询。

扩展更新后可在 `edge://extensions` 重新加载，再连接 AwaitOffer。切换源码目录后需要重新加载对应目录的扩展；不要修改清单中的固定公钥。

## 官网登录、验证码或解析异常

展开工作台的连接提醒，按提示去登录、去验证或检查连接。需要在官网正常完成验证，不支持自动获取短信或绕过验证码。官网主动使会话过期时，扩展不能延长会话。

如果官网有进度而面板未更新，先核对投递和岗位是否匹配，再查看本机诊断。提交问题只提供脱敏后的错误与字段结构，不上传真实备份、密钥或原始响应。

## 修改源码后页面仍是旧版

正式启动使用 `dist/` 和 `dist-server/`。修改后重新运行 `npm.cmd run build` 并重启服务；先完成正在进行的人工验证。开发时使用 `npm.cmd run dev`，访问 http://127.0.0.1:5173。
