# 备份与恢复

在侧栏或“设置 → 数据与备份”中导出 JSON。备份包含投递、官网连接配置、历史、刷新摘要、定时设置和删除忽略项。

当前导出格式为 v2，恢复支持 v1 和 v2，单文件上限 16MB。文件格式、字段类型和数据引用会被校验；无效文件不会覆盖当前数据。

## 恢复步骤

1. 打开“设置 → 数据与备份 → 恢复备份”。
2. 选择 AwaitOffer 导出的 JSON，核对记录数量。
3. 确认恢复。当前数据先保存到 `data/backups/`，然后用备份替换。
4. 检查 Edge 扩展连接与官网有效登录，重新验证自动连接。

备份不包含 Cookie、网页登录状态、扩展配对令牌和 AI 密钥。恢复不会替换当前机器单独保存的 AI 密钥；需要清除时请在设置中操作。

## 本地文件

```text
data/
  awaitoffer.sqlite       投递、设置、历史与任务
  awaitoffer.sqlite-wal   SQLite 运行文件，可能存在
  awaitoffer.sqlite-shm   SQLite 运行文件，可能存在
  backups/               恢复前的自动备份
  diagnostics/           读取和解析诊断
  edge-bridge.json        本机扩展配对信息
  llm.json                可选 AI 密钥，配置后存在
```

`data/` 独立于构建输出，重新构建不会清空它。日常备份优先使用界面导出；如需复制完整数据库目录，请先停止本地服务，避免漏掉 WAL 中尚未合并的写入。

JSON 备份含个人求职记录，请妥善保管，不要提交到公开仓库或作为问题附件上传。
